# Healthcare data analysis using R
## OVERVIEW
This project demonstrates an end-to-end data analytics workflow in R using the Indian Liver Patient Dataset. The analysis focuses on transforming raw healthcare data into meaningful insights through data preparation, cleaning, exploratory data analysis (EDA), and visualisation.

The objective was to identify trends, relationships, and anomalies within the dataset while demonstrating practical data analytics techniques commonly used in industry. The project highlights how data-driven insights can support informed decision-making within healthcare organisations.
## SKILLS USED
R; RStudio; Data Cleaning; Data Preparation; Exploratory Data Analysis (EDA); Statistical Analysis; Data Visualisation; ggplot2; dplyr; tidyverse; Feature Engineering; Data Quality Assessment; Data Analysis.
## PROJECT TASKS
### Dataset
This patient liver data is a publicly available dataset from [UC Irvine Machine Learning Repository.]( https://archive.ics.uci.edu/dataset/225/ilpd+indian+liver+patient+dataset)
### Data Preparation and Cleaning
The dataset was inspected and cleaned to improve data quality and ensure reliable analysis. This included:

Identifying and removing missing values;
Detecting and removing duplicate records
Verifying data types and dataset structure;
Detecting outliers using the Interquartile Range (IQR) method;
Creating a new calculated variable (Globulin) through feature engineering;
Preparing a clean dataset suitable for statistical analysis and visualisation.

This stage demonstrates the importance of data quality management before carrying out any analytical work.
### Exploratory Data Analysis
Statistical analysis was performed to better understand the characteristics of the dataset. Examples include:

Summary statistics for patient demographics and clinical measurements;
Analysis of age distributions within the patient population;
Investigation of relationships between liver health indicator;
Identification of trends, potential anomalies, and outliers;
Examination of gender-based differences within the dataset.

The project demonstrates the use of descriptive statistics, data profiling, and analytical reasoning to generate meaningful insights.
### Data Visualisation
R and ggplot2 were used to create visualisations that communicate key findings from the dataset, including:

Boxplots to analyse the Albumin and Globulin Ratio;
Frequency plots comparing age distributions by gender;
Scatter plots examining the relationship between Total Bilirubin and Direct Bilirubin;
Bar charts comparing average enzyme levels (ALP, ALT, and AST).

These visualisations help identify patterns, correlations, and potential business or healthcare insights within the data.
